💻웹체크인 방법
  • 시작 시기출항 30일 ~ 2일 전
  • 사이트msccruises.com (My Booking 또는 앱)
  • 필수예약번호 · 여권 · 사진 업로드 · 도착 시간 슬롯 선택
  • 결과물E-Ticket · 짐 태그 (인쇄)
⏰ 도착 시간 슬롯 MSC는 터미널 혼잡 방지로 도착 시간을 미리 지정해요. 인기 시간(11~12시)은 일찍 사라지니 체크인 열리자마자 잡기!

  • 앱 이름MSC for Me

03 · 승선 당일

터미널 → 객실까지

지정된 시간 슬롯에 도착

1
지정 시간 도착

웹체크인 때 선택한 도착 슬롯에 맞춰 도착. 너무 일찍 가면 대기. 너무 늦으면 정신없음.

2
짐 위탁

큰 짐은 터미널 입구 포터에게 위탁. 짐 태그 확인. 객실 배달은 오후.

3
체크인 · 보안검색

여권 + E-Ticket 제시 → MSC 크루즈 카드 / 손목밴드 수령 → 보안검색.

4
승선 · 안전훈련

배에 오르면 환영 음료 제공. 출항 전 비상 안전훈련 필수 (앱으로 사전 시청 가능).

5
첫날 꼭 할 것

① 앱에서 정찬 시간 확인 ② 음료 패키지/스파/특식당 예약 ③ Aurea 이상이면 전용 라운지·풀 위치 확인

⚠️ 크루즈 카드/밴드 방 열쇠 + 결제 + 출입. 손목밴드는 방수라 수영장에서도 OK.

05 · 기항지

내릴 때 · 탈 때

🃏꼭 챙길 것
  • 카드/밴드하선·승선 시 스캔 필수
  • 여권유럽 솅겐권은 사본 OK · 비솅겐은 원본 권장
  • 현지 화폐유로/달러 소액 + 신용카드
⏰ 복귀 시간 출항 1시간 전까지 무조건 승선. 앱과 객실 TV로 매일 안내. 늦으면 배가 먼저 떠납니다.
🚌익스커션 vs 자유여행
  • 익스커션앱에서 사전/현장 예약. 늦어도 배 기다려줌
  • 자유여행유럽 항구는 시내 접근성 좋아 자유여행 추천
  • 여행팁먼 곳·복잡한 곳만 익스커션, 나머지는 자유
06 · 하선

마지막 날

1
전날 밤 짐 정리

큰 짐 객실 문 앞에 (정해진 시간 전). 컬러 짐 태그 부착. 여권·귀중품·다음날 입을 옷은 휴대.

2
하선 그룹/시간 확인

앱과 객실에 컬러/번호로 하선 시간 안내. 익스프레스 하선(직접 짐 들고) 선택 시 가장 빨라요.

3
아침 식사

뷔페 6:30~8:30 권장. 마지막 날은 일찍 닫혀요.

4
하선 · 짐 찾기

크루즈 카드 스캔 후 하선 → 터미널 컬러 구역에서 짐 찾기 → 입국 심사.

💳 최종 청구서 앱에서 실시간 확인 가능. 의문스러운 항목은 마지막 날 밤 게스트 서비스에서 정정.
